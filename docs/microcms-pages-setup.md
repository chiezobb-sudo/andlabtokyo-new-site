# microCMS「pages」API セットアップ手順

トップページをCMS管理画面から編集できるようにするための設定手順です。

---

## 1. pages API を新規作成

microCMS 管理画面 → **「API」→「APIを追加」**

| 項目 | 値 |
|------|-----|
| API名 | pages |
| エンドポイント | `pages` |
| APIの種類 | **リスト形式** |

---

## 2. フィールドを追加

「APIスキーマ」画面で以下のフィールドを作成します。

### 基本フィールド

| フィールドID | 表示名 | 種類 |
|---|---|---|
| `slug` | スラッグ (例: home) | テキストフィールド |
| `metaTitle` | SEOタイトル | テキストフィールド |
| `metaDescription` | SEO説明文 | テキストエリア |
| `ogImage` | OGP画像 | 画像 |
| `blocks` | ページブロック | **繰り返しフィールド** |

### blocksの中にカスタムフィールドを5つ追加

`blocks`フィールドを作成したら「カスタムフィールドを追加」で以下を登録します。

---

#### ① hero（ヒーロー）

| フィールドID | 表示名 | 種類 |
|---|---|---|
| `eyebrow` | 上部ラベル（例: 東京・渋谷 / ELLE gourmet...） | テキストフィールド |
| `mainCopy` | メインコピー（h1） | テキストフィールド |
| `accentWord` | 金色強調語（mainCopyの中の1語） | テキストフィールド |
| `subCopy` | サブコピー（メインの下に小さく表示） | テキストエリア |
| `ctaLabel` | CTAボタン①のラベル | テキストフィールド |
| `ctaUrl` | CTAボタン①のリンク先 | テキストフィールド |
| `ctaLabel2` | CTAボタン②のラベル（任意） | テキストフィールド |
| `ctaUrl2` | CTAボタン②のリンク先（任意） | テキストフィールド |
| `bgImage` | 背景画像（未設定→ダーク背景） | 画像 |

---

#### ② courseGrid（講座グリッド）

| フィールドID | 表示名 | 種類 |
|---|---|---|
| `label` | セクションラベル（英語 例: COURSES） | テキストフィールド |
| `heading` | 見出し | テキストフィールド |
| `items` | 講座リスト | **繰り返しフィールド** |

`items`の中にカスタムフィールド `courseItem` を追加:

| フィールドID | 表示名 | 種類 |
|---|---|---|
| `cat` | カテゴリ名（英語） | テキストフィールド |
| `name` | 講座名（日本語） | テキストフィールド |
| `url` | リンク先URL | テキストフィールド |
| `theme` | 色テーマ | セレクトフィールド |

セレクトの選択肢:
- `choco` → ローチョコ（茶系）
- `ferm` → 発酵（緑系）
- `raw` → ローフード（深緑）
- `workshop` → ワークショップ（金系）
- `patis` → パティスリー（琥珀）

---

#### ③ knowledgeGrid（ナレッジ一覧）

| フィールドID | 表示名 | 種類 |
|---|---|---|
| `label` | セクションラベル（例: KNOWLEDGE） | テキストフィールド |
| `heading` | 見出し | テキストフィールド |
| `count` | 表示件数（未設定→3件） | 数値フィールド |

> 記事は knowledge API から自動取得します。ここでは表示数だけ指定。

---

#### ④ profileBand（プロフィール）

| フィールドID | 表示名 | 種類 |
|---|---|---|
| `label` | セクションラベル（例: ABOUT） | テキストフィールド |
| `name` | 氏名（日本語） | テキストフィールド |
| `nameEn` | 氏名（英語） | テキストフィールド |
| `subText` | 肩書き・所属 | テキストフィールド |
| `description` | 本文 | テキストエリア |
| `ctaLabel` | CTAラベル | テキストフィールド |
| `ctaUrl` | CTAリンク先 | テキストフィールド |
| `image` | プロフィール画像 | 画像 |

---

#### ⑤ richSection（フリーセクション）

| フィールドID | 表示名 | 種類 |
|---|---|---|
| `label` | セクションラベル | テキストフィールド |
| `heading` | 見出し | テキストフィールド |
| `body` | 本文 | **リッチエディター** |
| `image` | 画像（任意） | 画像 |
| `imagePosition` | 画像の位置 | セレクトフィールド |
| `ctaLabel` | CTAラベル（任意） | テキストフィールド |
| `ctaUrl` | CTAリンク先（任意） | テキストフィールド |

imagePositionの選択肢: `right` / `left` / `none`

---

## 3. コンテンツを作成

API作成後、**「コンテンツを追加」** から home ページを作成:

1. `slug` に **`home`** と入力（これがサイトに反映される）
2. `blocks` に各ブロックを追加していく
3. ブロックの順番がそのままページの上から下の構成になります

---

## 4. 公開 → 自動デプロイ

microCMSで「公開」を押す → Vercel webhook → 自動ビルド → サイトに反映

（webhook の設定がまだの場合は別途設定してください）

---

## 変更できること

| やりたいこと | 操作 |
|---|---|
| ヒーローのコピーを変更 | `hero`ブロックの`mainCopy`を編集 |
| 講座の並び順を変更 | `courseGrid`の`items`をドラッグで並び替え |
| ナレッジの表示件数を変えたい | `knowledgeGrid`の`count`を変更 |
| セクションを追加 | `blocks`に新しいブロックを追加 |
| セクションを消す | `blocks`からそのブロックを削除 |
| セクションの順番を入れ替え | `blocks`をドラッグで並び替え |
